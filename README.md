# 에듀코스트 — 학교시설 설계내역서 대시보드

브라우저에서 도는 설계내역서 작성·검토 도구입니다. 서버도, 계정도, 설치도 없습니다.

주소: <https://seum8660.github.io/educost/>

## 무엇을 하는 도구인가

적산 프로그램이 넘긴 설계내역서 엑셀(6시트)을 그대로 열고, 일위대가 호표와 단가를
직접 고칩니다. 고치면 일위대가 → 내역서 → 집계표 → 원가계산서까지 다시 계산됩니다.
끝나면 수식을 살려 엑셀로 내보냅니다.

- 여섯 시트를 원본 서식(글꼴·괘선·숫자서식) 그대로 봅니다
- 셀을 누르면 원본 수식이 보이고, 고친 셀은 되돌릴 수 있습니다
- 지난 내역서를 오른쪽에 나란히 열어 공종·세부품명을 끌어다 담습니다
- 반기 노임단가와 현행 제비율을 골라 한 번에 적용합니다
- 물량산출을 산출식·스케치로 잡아 내역서 수량으로 넘깁니다
- 자체 검토가 수량 누락, 끊긴 수식, 요율 이상, 재료비 단가를 짚습니다

## 쓰는 방법

**깃허브 페이지로 (팀 공유)**
Settings → Pages → Source를 `main` / `/ (root)` 로 두면 주소가 만들어집니다.
팀원은 그 주소를 열면 됩니다.

**파일로 (업무망 · 외부 접속이 막힌 경우)**
`educost-standalone.html` 하나만 공유폴더에 두고 각자 더블클릭합니다.
표준 일위대가가 안에 들어 있어 다른 파일이 필요 없습니다.

크롬 또는 엣지에서 엽니다.

## 파일

| 파일 | 용도 |
|---|---|
| `index.html` | 본체. 깃허브 페이지가 이 파일을 엽니다 |
| `educost-standalone.html` | 단독본. 표준 일위대가 3종 내장, 파일 하나로 실행 |
| `data/ilwi-*.json` | 표준 일위대가 (건축 · 기계·설비 · 토목) |
| `robots.txt` | 검색 노출 차단 |
| `.nojekyll` | 깃허브 페이지가 `index.html`을 그대로 내보내게 합니다 |

## 데이터가 어디 있는가

작업 내용은 여는 사람의 **브라우저 안에만** 남습니다 (localStorage · IndexedDB).
바깥으로 보내는 통신이 없습니다. 서버도, 계정도, 로그도 없습니다.

불러온 엑셀의 수식은 셀 참조·숫자·연산자·지원 함수만 계산하고, 그 밖의 글자가 섞인
수식은 실행하지 않습니다. 화면끼리 주고받는 데이터도 같은 대시보드 안에서만 오갑니다.

확인하고 싶으시면 인터넷을 끊고 써 보십시오. 로컬 모델을 쓰지 않는다면 모든 기능이
그대로 됩니다. F12 → Network 탭을 켜 두고 파일을 넣어 봐도 나가는 요청이 없습니다.

PC나 브라우저를 바꾸면 작업 내용이 따라오지 않으니 필요하면 엑셀로 내보내 두십시오.

## 간단내역서에서 가져오기 (암호 파일)

간단내역서에서 암호를 걸어 내보낸 `.educost` 파일을 「엑셀 파일 열기」로 엽니다.
암호를 넣으면 이 PC 안에서만 풀어 6시트 내역서로 만듭니다. 서버를 거치지 않습니다.

- 암호화: AES-256-GCM, 암호에서 키를 만들 때 PBKDF2-SHA256 (브라우저 내장 Web Crypto)
- 암호는 파일에 들어가지 않습니다. 잊으면 누구도 풀 수 없습니다.
- 파일이 새어 나가도 암호 없이는 내용을 볼 수 없지만, 암호는 파일과 **다른 경로**로 전하십시오.

## 내역서 모음

내역서 모음 탭에서 「팀 공유폴더 연동」을 누르고 내역서가 모여 있는 폴더를 고릅니다.
폴더 안의 엑셀을 읽어 카드로 만들고, 그 뒤로는 화면을 열 때마다 새로 들어온 파일만
자동으로 붙습니다. **연결은 한 번만 하면 됩니다.**

팀원은 각자 PC에서 같은 폴더를 한 번씩 연결하면 같은 카드를 보게 됩니다.
엑셀은 각자 PC 안에서만 읽히고 어디로도 보내지 않습니다.
한두 건만 보탤 때는 「엑셀 직접 추가」를 씁니다.

브라우저를 완전히 닫았다 켠 뒤 처음 열 때 「이 폴더를 계속 볼까요」를 한 번 물을 수
있습니다. 「허용」을 누르면 끝이고, 폴더를 다시 고르는 것이 아닙니다.

## AI 도우미

이 PC(또는 사내 PC)에서 도는 **로컬 모델**에만 묻습니다. 외부 AI 서비스를 부르지 않습니다.
모델 주소는 이 PC(`localhost`)나 내부망 주소(10.x · 172.16~31.x · 192.168.x)만 받습니다.
그 밖의 주소는 입력 단계와 전송 직전에 모두 막아, 내역이 외부 서버로 나가지 않습니다.
쓰려면 올라마(Ollama) 또는 LM Studio를 깔고, 상단 「로컬 모델 설정」에
서버 주소와 모델 이름을 넣습니다.

| 도구 | 주소 | 준비 |
|---|---|---|
| 올라마 | `http://localhost:11434/v1` | 실행 전 `OLLAMA_ORIGINS=https://seum8660.github.io` |
| LM Studio | `http://localhost:1234/v1` | Developer 탭에서 서버 켜기 |

`OLLAMA_ORIGINS=*` 는 쓰지 마십시오. 그 PC에서 여는 **모든 웹사이트**가 올라마를 부를 수
있게 됩니다. 이 주소(`https://seum8660.github.io`)만 허용하면 됩니다.
단독본(파일)으로 쓰다가 연결이 안 될 때만 개인 PC에 한해 `*` 를 쓰고, 서버로 쓰는 PC에는
쓰지 않습니다.

한 대만 서버로 쓰려면 그 PC에 `OLLAMA_HOST=0.0.0.0` 을 넣고, 나머지 PC는
`http://그PC주소:11434/v1` 을 적습니다. 이때는 **같은 망의 누구나** 접속할 수 있으므로
윈도우 방화벽에서 11434 포트를 팀 PC 주소로만 열어 두고, 외부망에는 절대 열지 않습니다.

안 깔아도 나머지 기능은 모두 됩니다.
